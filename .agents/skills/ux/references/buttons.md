# Buttons

The same job uses the same variant everywhere.

`default` moves forward: confirm, continue, connect. It stays `default` when it is the only button.

`secondary` steps back: cancel, and a Close with a label.

`destructive` is the damaging confirm: remove, delete, sign out.

`outline` is a bordered control for a job on the page: copy, refresh, try again, or a row action that opens another step.

`ghost` has no fill and no border. A light wash appears on hover. Use it when the control should not look like a button: the close mark in a corner, sign out in a sidebar, a plus on a list row, a picker in the composer. Line the icon and the label up with the text beside them. The wash is larger than the icon. Align the icon and the label, not the wash.
