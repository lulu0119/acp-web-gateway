# How desktop apps keep a background process running

Status: consumed by [ADR 0018](../adr/0018-the-desktop-app-is-a-tauri-tray.md).

Researched 2026-10-15 for [ADR 0018](../adr/0018-the-desktop-app-is-a-tauri-tray.md). Links are pinned to commits.

## Who starts the process

- **Desktop apps own the process.** Ollama's app starts `ollama serve` as a hidden child and starts it again one second after it exits ([server.go](https://github.com/ollama/ollama/blob/8e4dad49f9f527762610fd419ee2ae39207f67a4/app/server/server.go#L178-L228), [server_windows.go](https://github.com/ollama/ollama/blob/8e4dad49f9f527762610fd419ee2ae39207f67a4/app/server/server_windows.go#L22-L30)). The GitHub Actions runner restarts its listener from a Node supervisor, not from launchd or systemd ([RunnerService.js](https://github.com/actions/runner/blob/796cc18ffaaafd5cea525d6231f5a8c93c11c603/src/Misc/layoutbin/RunnerService.js#L139-L141)). opencodex's Tauri app runs a Bun-compiled CLI as a sidecar and asks that CLI for state and stop results as JSON instead of reading its files ([sidecar.rs](https://github.com/lidge-jun/opencodex/blob/409026b1bcb184e523ccc4f22930dc0a5a6ffa01/desktop/src-tauri/src/sidecar.rs#L195-L212), [ownership.rs](https://github.com/lidge-jun/opencodex/blob/409026b1bcb184e523ccc4f22930dc0a5a6ffa01/desktop/src-tauri/src/ownership.rs#L1-L16)).
- **CLIs install system services.** cloudflared, ngrok, and Tailscale install a launchd daemon, a system systemd unit, or a Windows service, which need an administrator ([cloudflared windows_service.go](https://github.com/cloudflare/cloudflared/blob/cfb7560389a6071648370fca3182c9f67d934b92/cmd/cloudflared/windows_service.go#L351-L372), [tailscaled install_windows.go](https://github.com/tailscale/tailscale/blob/b83f28ebfbd9f86c2543e30e9dcf035a417dce1e/cmd/tailscaled/install_windows.go#L38-L92)). None of them creates a Windows logon task. Syncthing ships example launchd and systemd user files and documents the Windows Task Scheduler by hand ([user unit](https://github.com/syncthing/syncthing/blob/d70d210320c4dcce67774c5bf1f545912b99e5d8/etc/linux-systemd/user/syncthing.service#L1-L27), [autostart docs](https://github.com/syncthing/docs/blob/25904513a60a95e0f9a61e52d3abc0a77ab7fea9/users/autostart.rst#L29-L150)).

## Windows logon tasks, measured

On Windows 11 25H2 as a standard user: a task with a `LogonTrigger` for the current user, `InteractiveToken`, and `LeastPrivilege` registers without elevation. A console program it starts opens a Windows Terminal window; wrapped in `conhost.exe --headless` it opens none, but the task then records exit code 0 for a program that exited with 3, and `RestartOnFailure` did not start it again. Syncthing instead embeds `consoleAllocationPolicy=detached` in its manifest, which Windows 11 24H2 and later honour ([manifest](https://github.com/syncthing/syncthing/blob/d70d210320c4dcce67774c5bf1f545912b99e5d8/assets/windows/syncthing.exe.manifest#L1-L8)).

## Tauri tray apps

- All of nym-vpn-app, opencodex, clash-verge-rev, and aw-tauri build the tray in Rust and update menu items with `set_text` on kept handles. Rebuilding the menu while it is open crashes on macOS ([screenpipe tray.rs](https://github.com/mediar-ai/screenpipe/blob/86e0c0a2c5105fcff914b44d060f180bdbbb639f/apps/screenpipe-app-tauri/src-tauri/src/tray.rs#L626-L641)).
- clash-verge-rev's lightweight mode destroys the window and keeps the app alive by calling `prevent_exit` when `ExitRequested` has no code ([lib.rs](https://github.com/clash-verge-rev/clash-verge-rev/blob/c6b51171a1db9b75a4270d78944e132293dbdd83/src-tauri/src/lib.rs#L405-L417)).
- On Windows, clash-verge-rev replaces the autostart plugin with a logon task, and opencodex writes the `HKCU\…\Run` value itself with a quoted path, because the plugin's default tries HKLM first and writes an unquoted command ([auto-launch windows.rs](https://github.com/zzzgydi/auto-launch/blob/107a5bda45a583ebe4795fff13207e0e3c483702/src/windows.rs#L46-L78)).
- On Linux, `TrayIconBuilder::build()` succeeds on stock GNOME although no icon appears, and a missing libappindicator panics ([libappindicator-sys](https://github.com/tauri-apps/libappindicator-rs/blob/d3af4b3a51c0bf208d4aec23305d5ef6f1785e0a/sys/src/lib.rs#L14-L52)). opencodex asks D-Bus for `org.kde.StatusNotifierWatcher` and, with no answer, shows its window and makes close mean quit ([tray_availability.rs](https://github.com/lidge-jun/opencodex/blob/409026b1bcb184e523ccc4f22930dc0a5a6ffa01/desktop/src-tauri/src/tray_availability.rs#L34-L99)).

## PATH

The GitHub Actions runner writes `PATH` to a file when it is configured and restores it when the service starts ([env.sh](https://github.com/actions/runner/blob/796cc18ffaaafd5cea525d6231f5a8c93c11c603/src/Misc/layoutroot/env.sh#L37), [runsvc.sh](https://github.com/actions/runner/blob/796cc18ffaaafd5cea525d6231f5a8c93c11c603/src/Misc/layoutbin/runsvc.sh#L7-L11)). Ollama's Linux installer writes `Environment="PATH=$PATH"` into its unit ([install.sh](https://github.com/ollama/ollama/blob/8e4dad49f9f527762610fd419ee2ae39207f67a4/scripts/install.sh#L215-L230)).
