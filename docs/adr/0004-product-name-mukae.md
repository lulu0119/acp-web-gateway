# Product name: Mukae

The product needed a sayable name that means calling a presence in, not the stack. Decided: Mukae, Japanese 迎え, going out to meet an arrival and bring them inside. The rename is total: CLI, `mukae://` launch scheme, config path, npm scope, and display name. Nothing was committed or installed yet, so no migration.

## Considered Options

- **Ahuti**: Vedic fire offering that calls gods down. Clean registries. Set aside: welcoming-inside fits the gateway act more directly.
- **Calare**: Latin calare, to call out. Clean registries. Set aside: proclaiming is broader than bringing inside.
- **Kahea**: Hawaiian for call. Rejected: KAHEA, an active Hawaiian nonprofit, holds the name.
- **Collision note**: `pleme-io/mukae` (0-star Rust login manager, same etymology, active) and `poppykae/mukae` (dead empty repo) exist on GitHub; npm and PyPI are empty. Accepted: neither has users, product, or standing. Trademark registries were not searched.
